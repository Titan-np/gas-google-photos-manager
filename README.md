# [GASから操作可能なGoogleフォト管理](https://github.com/Titan-np/gas-google-photos-manager)

Googleフォトの Library API は、同じOAuthクライアントが作成したアルバム・写真しか操作できません。  
そこで、OAuth2認証とGoogleフォトの操作を本プロジェクトに集約し、他のGASプロジェクト（ホスト側）へライブラリとして提供します。

---

## 動作環境

- Google Apps Script（V8ランタイム）
- Google Cloud Console のプロジェクト（Photos Library API・OAuthクライアントID）
- 管理用の Google スプレッドシート（本プロジェクトのコンテナ）

## 使い方

- ライブラリの識別子：`MyGooglePhotos`
- アルバムの作成・一覧の確認：管理スプレッドシートのメニュー「Googleフォト管理」から行います。
- 写真のアップロードなど：ホスト側から `MyGooglePhotos.関数名()` で呼び出します。

### APIの使い方

| 分類       | 関数                                    | 内容                                                                          |
| ---------- | --------------------------------------- | ----------------------------------------------------------------------------- |
| 認証       | `isAuthorized()`                        | 認可済みかどうかを返す                                                        |
| 認証       | `getRedirectUri()`                      | OAuthクライアントに登録するリダイレクトURIを返す                              |
| 認証       | `getAuthorizationUrl()`                 | 認可ページのURLを返す                                                         |
| 認証       | `handleAuthCallback(request)`           | 認可完了時のコールバック処理（ライブラリ内部の `authCallback_` から呼ばれる） |
| 認証       | `resetAuth()`                           | 認可情報をリセットする                                                        |
| デバッグ   | `logAuthorizationGuide()`               | 認可の手順と、リダイレクトURI・認可URLをログ出力する                          |
| デバッグ   | `logRuntimeContext()`                   | 実行中のスクリプトIDと、参照できるスクリプトプロパティのキー名をログ出力する  |
| アルバム   | `createAlbum(title)`                    | アルバムを作成する                                                            |
| アルバム   | `listAlbums()`                          | アルバムの一覧を取得する                                                      |
| 写真・動画 | `uploadFile(driveFile, albumId)`        | ドライブのファイルをアップロードし、アルバムへ追加する                        |
| 写真・動画 | `listMediaItems(albumId, maxItems)`     | アルバム内の写真・動画の一覧を取得する                                        |
| 写真・動画 | `buildImageUrl(baseUrl, width, height)` | サイズ指定付きの表示用URLを組み立てる                                         |

失敗時は例外を投げます。複数ファイルを処理する場合は、ホスト側で1件ずつ try/catch してください。

```javascript
// 写真アップロード
MyGooglePhotos.uploadFile(driveFile, albumId);

// アルバム内の写真を、フルHDサイズの表示用URLで取得する
const imageUrls = MyGooglePhotos.listMediaItems(albumId, 50).map((mediaItem) => MyGooglePhotos.buildImageUrl(mediaItem.baseUrl, 1920, 1080));
```

### フォルダ構成

- `src/`：GASのソース（clasp push / pull の対象）
- `docs/`：GitHub Pages で公開するページ（OAuth同意画面のホームページ・プライバシーポリシー・利用規約）

## 初期設定

### 1. Google Cloud Console

1. Photos Library API を有効にします。
2. 公開ステータスを「本番環境」にします（「テスト」のままだと、リフレッシュトークンが7日で失効します）。
3. OAuthクライアントID（種類：ウェブアプリケーション）を作成し、クライアントIDとシークレットを控えます。

### 2. 本プロジェクト（ライブラリ側）

1. スクリプトプロパティに、以下を設定します（ホスト側への設定は不要です）。
   - `GOOGLE_PHOTOS_CLIENT_ID`：クライアントID
   - `GOOGLE_PHOTOS_CLIENT_SECRET`：クライアントシークレット
2. 管理スプレッドシートを開き、メニュー「Googleフォト管理」→「認可の手順を表示」を実行します。
3. 表示された手順に従い、リダイレクトURIをOAuthクライアントの「承認済みのリダイレクトURI」へ登録してから、認可ページを開いて許可します。
4. メニュー「シートを初期化」で、シート「アルバム」を作成します。

### 3. アルバムの用意

1. シート「アルバム」の「タイトル」列にタイトルを入力し、その行を選択します。
2. メニュー「選択行のアルバムを作成」を実行します。
3. シートに表示された「アルバムID」を控えます。

既存のアルバム（同じOAuthクライアントで作成したもの）は、メニュー「アルバム一覧を同期」で取り込めます。

### 4. ホスト側プロジェクト

1. ライブラリを、識別子 `MyGooglePhotos` で追加します。
2. 控えたアルバムIDを、ホスト側のスクリプトプロパティ（例：`SCREENSHOT_ALBUM_ID`）へ保存します。
3. 「APIの使い方」を参考に、 `MyGooglePhotos.関数名()` を呼び出す処理を書きます。

ホスト側での認可や、認可用の関数（`authCallback_` など）は不要です。

- ライブラリ内の処理は、ホスト側から呼ばれた場合も、ライブラリ側のスクリプトプロパティとユーザープロパティを参照します（`MyGooglePhotos.logRuntimeContext()` で確認済み）。  
  そのため、クライアントID・シークレットの設定と認可は、ライブラリ側で1回行えば、全てのホスト側で共通して使えます。
- 認可が切れた場合（アクセス権の取り消し、スコープの変更など）も、ライブラリ側のスプレッドシートのメニューから、認可をリセットして認可し直します。

## 制約・注意点

- アルバムの一覧に表示されるのは、同じOAuthクライアントで作成したアルバムのみです。
- `listMediaItems()` で取得できるのは、`uploadFile()` でアップロードした写真・動画のみです。
  - Googleフォトの画面からアルバムへ手動で追加した写真は、APIの仕様上取得できません。
- `baseUrl` の有効期限は約60分のため、保存せず、表示のたびに取得し直してください。
- アルバムはAPIから削除できません（不要になったらGoogleフォトの画面で削除します）。
- アップロードできるファイルサイズは、UrlFetchApp の上限（50MB）までです。
