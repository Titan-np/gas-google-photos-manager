GASから操作可能なGoogleフォト管理

概要

「GASから操作可能なGoogleフォト管理」（以下「本ツール」）は、開発者が自分のGoogleアカウントで利用するために作成した、個人用の Google Apps Script のツールです。 一般向けの公開・配布は行っていません。

主な機能

  • Googleドライブ上の画像を、利用者自身のGoogleフォトへアップロードする
  • 本ツールで作成したアルバムの作成・一覧の確認を行う
  • 本ツールでアップロードした写真・動画の一覧を取得する

Googleアカウントへのアクセスについて

本ツールは、Googleフォトへの写真の追加と、本ツール自身が作成したアルバム・写真の読み取りのみを行います。 それ以外の写真やアルバムにはアクセスしません。詳しくはプライバシーポリシーをご覧ください。

プライバシーポリシー

制定日：2026年10月10日

本ツールにおけるGoogleユーザーデータの取り扱いを、以下のとおり定めます。

1. アクセスするデータ

本ツールは、利用者の許可を得たうえで、以下の範囲に限りGoogleフォトへアクセスします。

  • 写真・動画のアップロードと、アルバムの作成（スコープ：photoslibrary.appendonly）
  • 本ツールが作成したアルバム・写真の情報の読み取り（スコープ：photoslibrary.readonly.appcreateddata）

本ツールが作成していない写真やアルバムにはアクセスしません。

2. 利用目的

取得したデータは、Googleドライブの画像をGoogleフォトへアップロードする機能と、アルバムを管理する機能のためにのみ利用します。

3. データの保存

  • 認可に必要なトークンは、Google Apps Script のプロパティ（利用者のGoogleアカウント内）に保存します。
  • 写真・動画は、利用者自身のGoogleドライブとGoogleフォトの間でのみ送受信します。
  • 開発者や第三者のサーバーへ、データを送信・保存することはありません。

4. 第三者への提供

取得したデータを第三者へ提供・販売することはありません。また、広告の目的には利用しません。

5. Google API サービスのユーザーデータに関するポリシーの遵守

本ツールにおけるGoogle APIから取得した情報の利用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

6. アクセス権の取り消し

本ツールへのアクセス権は、 Googleアカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

7. 本ポリシーの変更

本ポリシーの内容を変更する場合は、このページを更新します。
